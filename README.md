# DoyinTech API Dashboard

Web application that uses the **KYC API** and **Property AI API**.

Features:
- Live KYC tester (BVN, NIN, Document, Face Match)
- Live Property AI tester (descriptions, document analysis, summaries)
- API key creation & usage tracking
- Settings to point to your deployed APIs

## Quick Start

```bash
npm install
npm start
# open http://localhost:3000
```

1. Go to **Settings** and enter your deployed KYC + Property API URLs
2. Use the default key `dev-key-123` or create a new one
3. Test the APIs from the dashboard
